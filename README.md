This is the repository for accessibility and travel information for the IPPP. It contains accessibility information for rooms used in IPPP conferences as well as information for how to get to us (including accessible walking routes and bus information).

In this repository we have the guide in docx, odt, md and pdf formats. 

There is also an accessible [webpage of this guide](https://lti.chirun.org.uk/media/chirun-packages/output/657858aa-146b-4b76-9246-598154e928c0/index.html), generated using [Chirun](https://chirun.org.uk/).
